hey im rishith — this is my personal site

just a small static site i made to put my stuff in one place. has a little about me, some projects ive done, and ways to contact me. nothing fancy.

### whats in here

- `index.html` — all the content / structure
- `style.css` — all the styling (neubrutalist-ish yellow + chunky borders thing)
- thats it. no js framework, no build step.

### sections on the page

- hero with nav (about / projects / contact)
- about me — grade 10, into robotics, arduino/sensors, web dev, learning python + c++
- projects:
  - pocket pomodoro (browser focus timer)
  - line follower bot (arduino)
  - loot log (little rating thing with localstorage)
- contact — github / slack / email buttons
- footer

### how to run it

easiest way, just open it:

1. download / clone this repo
2. double click `index.html`

or if you want live reload in vscode, use the live server extension and right click index.html -> open with live server.

### fonts / colors

fonts are from google fonts (syne + space mono). colors are just css variables at the top of style.css if you wanna mess with them.
